## App Store Description

Master the CompTIA Project+ (PK0-005) exam with Project+ Vault — the most comprehensive, beautifully designed exam prep app built exclusively for iOS.

EVERYTHING YOU NEED TO PASS
- 200+ original practice questions across all 4 exam domains
- Questions mapped to official PK0-005 objectives (1.1–4.5)
- Multiple choice & multiple select formats — just like the real exam
- Detailed explanations with objective references for every question

SMART STUDY TOOLS
- Spaced repetition flashcards with SM-2 algorithm
- Mark questions as Mastered to track your progress
- Domain-by-domain study mode with progress bars
- Bookmark and review missed questions

4 FULL-LENGTH MOCK EXAMS
- 90 questions each — matching real PK0-005 format
- 90-minute countdown timer
- Weighted by official domain percentages (33%/30%/19%/18%)
- Deterministic exams (A/B/C/D) — retake and compare your improvement

BEAUTIFUL ANALYTICS
- Swift Charts dashboard with accuracy trends
- Domain mastery breakdown with exam weight visualization
- Streak heatmap (GitHub-style contribution grid)
- Weak area identification by sub-objective
- Difficulty performance donut charts
- Historical score trend tracking

DAILY MOTIVATION
- Streak counter to keep you on track
- Daily goal tracker (questions per day)
- Motivational quotes from thought leaders
- Time-of-day greetings

EXAM DOMAINS COVERED
- Domain 1.0: Project Management Concepts (33%)
- Domain 2.0: Project Life Cycle Phases (30%)
- Domain 3.0: Tools and Documentation (19%)
- Domain 4.0: Basics of IT and Governance (18%)

FREE TO START
- 50 free questions per day
- Basic practice quizzes
- Upgrade to Premium for unlimited access

PREMIUM FEATURES ($4.99/mo or $19.99 lifetime)
- Unlimited daily questions
- All 4 mock exams
- Full analytics dashboard
- Spaced repetition flashcards
- Weak area analysis
- Ad-free experience

Built with SwiftUI, iOS 18+, and designed with a beautiful dark vault theme.
